Featured Work

// PROJECT 01

StockSense AI

LSTM-based stock price forecasting web app. It pulls market data from Yahoo Finance, forecasts the next N days with confidence intervals, and presents everything in an interactive Streamlit dashboard.

  • 3-layer stacked LSTM built with Keras / TensorFlow
  • Evaluated with RMSE, MAE and MAPE
  • Plotly candlestick charts, moving averages and CSV export of forecasts
Python Keras TensorFlow Streamlit Plotly yfinance
GitHub Live demo coming soon
// PROJECT 02

Retinal AI

Team project (3) · My part: the ResNet-50 classifier

Retinal fundus image analysis system for diabetic retinopathy. My ResNet-50 classifier grades images into five severity levels; the full app adds U-Net vessel segmentation and YOLO lesion detection.

  • Input pipeline: CLAHE contrast enhancement, 224×224 resize, ImageNet normalisation
  • Reports class probabilities and prediction confidence
  • Full app: FastAPI backend, React interface, downloadable PDF reports
Python PyTorch ResNet-50 OpenCV U-Net YOLO FastAPI React
